## Reporting a Vulnerability

We take the security of the Agent Security Scanner seriously. If you believe you have found a security vulnerability, please follow these steps:

1. **Do Not** disclose the vulnerability publicly
2. Open a public GitHub issue

### What to Expect

- You will receive an acknowledgment within 48 hours
- We will investigate and keep you updated on our progress
- We will work with you to validate and address the vulnerability

## Security Best Practices

When using the Agent Security Scanner:

1. **Keep Updated**: Always use the latest version
2. **Secure Configuration**: Follow the security guidelines in our documentation
3. **Access Control**: Restrict access to the scanner in production environments
4. **Input Validation**: Validate all inputs before scanning
5. **Output Handling**: Securely handle scan results and reports
6. **Environment**: Run in a controlled environment with appropriate permissions

## Security Features

The Agent Security Scanner includes several security features:

- Safe YAML parsing
- Input validation
- Path traversal protection
- Rate limiting
- Resource constraints
- Audit logging
- Sandboxed execution
